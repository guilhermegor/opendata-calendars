# Ledger — #6 cache-data-only

Branch: `fix/6-cache-data-only-format` · Issue: #6 · Class: **security**

## Goal

The holiday cache no longer uses pickle: a poisoned cache file could run code on load.

## Work

- [x] Cache files are JSON (`pandas.to_json(orient="split", date_format="iso")`), one file per key,
  with the creation timestamp and column dtypes inside the file (`read_json` is banned by ruff TID251). pyarrow/fastparquet are not dependencies and a new
  heavy one is not justified for small holiday frames.
- [x] `.pkl` files left by older versions are ignored and never unpickled (not read, cleaned or cleared).
- [x] `# noqa: S301`/`S403` markers removed; `/tmp/cache` docstring example dropped.
- [x] Cache directory created with mode 0o700.
- [x] Tests: round trip with timestamp, stray `.pkl` not loaded.
